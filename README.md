# Последний сигнал

Космический survival-шутер на Python / Tkinter. Летайте по арене, прицеливайтесь мышью, уничтожайте дронов и собирайте комбинации улучшений.

## Запуск на Windows

1. Установите Python 3.10 или новее с компонентом Tcl/Tk (обычно включён по умолчанию).
2. Распакуйте весь архив.
3. В папке last_signal дважды нажмите start.bat.

Либо откройте терминал в этой папке:

```
python main.py
```

Пакеты pip и интернет для игры не нужны. Нужен экран, на котором помещается окно 1080 × 720 с рамкой. Если окно не помещается, уменьшите масштаб экрана в настройках ОС.
На macOS: python3 main.py с поддержкой Tkinter. На Linux может понадобиться системный пакет python3-tk.

## Управление

| Действие | Клавиши |
|---|---|
| Полёт | WASD в английской раскладке или стрелки |
| Прицел | Мышь |
| Стрельба | Удерживать левую кнопку мыши |
| Рывок | Пробел + направление движения |
| Пауза | P или Esc |
| Выбор улучшения | 1, 2, 3 или щелчок по карточке |
| Старт / повтор | Enter |

При потере фокуса бой ставится на паузу. Для продолжения вернитесь в окно и нажмите Esc.

## Правила

Уничтожьте всех врагов волны, чтобы выбрать одно из трёх случайных улучшений. После выбора сразу начинается следующая волна.

- Розовые треугольники — охотники, преследующие корабль.
- Жёлтые ромбы — стрелки, держащие дистанцию.
- Фиолетовые ромбы — медленные бронированные дроны.
- Каждую пятую волну появляется большой босс с круговыми залпами.
- Зелёные аптечки восстанавливают 20 здоровья и исчезают через 12 секунд.
- Рывок даёт короткую неуязвимость и перезаряжается 2,4 секунды. Удерживание пробела повторяет рывок, когда он готов.

Улучшения: урон, темп стрельбы, дополнительные снаряды (до пяти), запас здоровья, скорость и полный ремонт. Режим бесконечный: цель — набрать больше очков и пройти дальше.

Рекорд записывается при поражении и закрытии окна в .last_signal.json в домашней папке пользователя. Если запись недоступна, рекорд остаётся в памяти до закрытия программы.

## Устройство проекта

- main.py — окно, управление, отрисовка, рекорд.
- engine.py — бой, враги, волны и улучшения.
- start.bat — запуск Windows.
- tests/test_engine.py — проверки правил без открытия окна.

Корабли, снаряды, звёзды и частицы рисуются средствами Canvas. Отдельные изображения не нужны. Звука в этой версии нет.

## Проверки

Из папки last_signal:

```
python -m unittest discover -s tests -v
```

Проверяются движение, выстрелы, очки, рывок, улучшения, босс, смерть, границы арены, удаление снарядов и длительная симуляция. В среде сборки проверены правила и синтаксис. Графическое окно на Windows здесь не проверялось.

Ручная проверка: старт → движение и огонь → рывок → пауза → зачистка волны → выбор карточки → поражение → новая попытка → перезапуск и проверка рекорда.

## Идеи развития

Звук, несколько кораблей, новые арены, сохранение забега и достижения. Игровые правила отделены от интерфейса, поэтому их можно развивать отдельно.
